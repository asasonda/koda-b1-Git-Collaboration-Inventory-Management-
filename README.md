### information git collab yang harus dilakukan

- Setiap anggota wajib melakukan git clone dan membuat branch masing-masing berdasarkan fitur yang dikerjakan.
- Setiap anggota wajib membuat minimal 2 commit menggunakan Conventional Commits.
- Lakukan git push dan buat Pull Request (PR) untuk setiap branch.
- Lakukan code review sebelum menggabungkan perubahan ke branch main.
- Setelah merge, lakukan git pull dan pastikan semua fitur berjalan.
- Simulasikan minimal 1 merge conflict dengan mengubah bagian yang sama pada file di branch berbeda, kemudian selesaikan konflik tersebut.
